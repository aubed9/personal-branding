# DIGITAL MARKET — Phase 7: Visual Identity Design System

## 1. Input Prerequisites
- Locked Phase 6 `Visual Identity Design Brief` and Name/Tagline.
- Locked Phase 4 `Brand Identity & Character` (Archetype & Personality).

## 2. Core Visual Modules
1. **Color Strategy & Semantic Palette:**
   - Primary brand color (Strategic psychological anchor).
   - Secondary accent colors (Energy, call-to-action, hierarchy).
   - Neutral & obsidian base tones (Text, canvas, high-contrast readability).
   - Color ratio rules (e.g. 60-30-10 rule).
2. **Typography Architecture:**
   - Primary Persian typeface (Display & headings: bold, authoritative, distinctive).
   - Body Persian typeface (High legibility at small sizes, optimal line-height).
   - Secondary Latin typeface (Matching optical weight and modern character).
3. **Logo Morphology & Mark Strategy:**
   - Wordmark (Logotype) vs Monogram vs Abstract Symbol vs Emblem.
   - Clearspace, minimum size, monochrome inversion, and prohibited treatments.
4. **Graphic Devices & Visual Texture:**
   - Patterns, micro-borders, geometric angles, framing rules, photography style.
5. **Real-World Collateral Adaptations:**
   - For Local Service: Storefront signage, vehicle wrap, staff uniforms, receipt cards.
   - For Hospitality: Cups, bean pouches, menu board, physical coaster, packaging.
   - For B2B SaaS: Web UI tokens, dashboard theme, product screenshots, slide deck.
   - For Manufacturing: Product catalog, spec sheets, safety labels, factory signage.

## 3. Phase 7 Gate Verification
- [x] Color palette calibrated with precise hex codes and psychological rationale.
- [x] Typography system selected and documented.
- [x] Logo rules and collateral applications specified.
- [x] Formal `Visual Identity Design System` (کتابچه هویت بصری و دیزاین سیستم) generated.
- [x] Handed off to Phase 8 via `Executive Activation Brief`.
