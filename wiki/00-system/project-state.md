# مفهوم چیست؟
مخزن داده‌ای متمرکز و ساخت‌یافته (JSON/YAML) که تمامی متغیرهای بافتار، تصمیمات، فکت‌ها، فرضیات و مجهولات پروژه را ذخیره می‌کند.

# چرا اهمیت دارد؟
جلوگیری از فراموشی اطلاعات در گفتگوهای طولانی و امکان ادغام با سامانه‌های نرم‌افزاری.

# چه زمانی استفاده می‌شود؟
در هر تعامل و ثبت پاسخ توسط کاربر.

# چه زمانی نباید استفاده شود؟
برای ثبت پیام‌های چت عادی غیرحاوی تصمیم یا فکت.

# برای چه نوع کسب‌وکارهایی مهم‌تر است؟
تمام پروژه‌های تحت هدایت دیجیتال مارکت.

# سؤال‌هایی که برای کشف آن باید پرسیده شود
- شناسه تصمیم چیست؟\n- وضعیت فرضیه (تاییدشده یا در انتظار تحقیق) چگونه است؟

# داده‌های موردنیاز
ورودی‌های متنی و گزینه‌ای کاربر، نتایج ارزیابی هوش مصنوعی.

# نحوه تحلیل
صحت‌سنجی در برابر اسکیماهای استاندارد `project-state.schema.json`.

# مثال ساده
مانند پرونده پزشکی بیمار که تمام سوابق، آزمایش‌ها و نسخه‌ها در آن ثبت و به روز می‌شود.

# مثال تخصصی
ذخیره فکت `F-P1-03: تمرکز جغرافیایی روی شهر اصفهان` که باعث فیلتر شدن رقبای تهران در فاز ۲ می‌شود.

# اشتباهات رایج
- ذخیره داده‌های نامعتبر بدون شناسه یا بدون ارجاع به فاز مبدا.

# ارتباط با سایر مفاهیم
متصل به `KB-SYS-EVIDENCE-001` و `KB-SYS-TRACE-001`.

# تأثیر روی فازهای بعدی
تغذیه مستقیم داشبورد فرانت‌اند و تولید کتابچه جامع نهایی.

# KPI / Signals
انطباق ۱۰۰٪ با اسکیما، بازیابی آنی اطلاعات.
