# مفهوم چیست؟
فروش مستقیم کالا از طریق وب‌سایت، اینستاگرام یا پلتفرم‌های واسط با ارسال مرسوله پستی.

# چرا اهمیت دارد؟
تکیه بر ترافیک دیجیتال نیازمند جلب اعتماد سریع و کاهش هزینه‌های بسته‌بندی و لجستیک است.

# چه زمانی استفاده می‌شود؟
با فعال شدن اورلی `ECOMMERCE_DTC`.

# چه زمانی نباید استفاده شود؟
برای خدمات حضوری بدون فروش کالا.

# برای چه نوع کسب‌وکارهایی مهم‌تر است؟
فروشگاه‌های آنلاین پوشاک، لوازم خانگی، اکسسوری، مکمل‌های ورزشی و کتاب.

# سؤال‌هایی که برای کشف آن باید پرسیده شود
- نرخ رهاسازی سبد خرید چقدر است؟- چند درصد مشتریان خرید مجدد دارند؟- زمان تحویل مرسوله چقدر است؟

# داده‌های موردنیاز
آمار گوگل آنالیتیکس، درگاه پرداخت، هزینه بسته‌بندی و پست، نرخ مرجوعی کالا.

# نحوه تحلیل
تحلیل قیف فروش آنلاین (Traffic -> Product Page -> Cart -> Checkout -> Delivery).

# مثال ساده
آنلاین‌شاپی که شال و روسری را با بسته‌بندی عطرآگین در کمتر از ۴۸ ساعت به دست مشتری می‌رساند.

# مثال تخصصی
یک برند مد و پوشاک DTC که با پیاده‌سازی گارانتی تعویض سایز رایگان، نرخ تبدیل سایت را ۲ برابر کرده است.

# اشتباهات رایج
- وابستگی ۱۰۰٪ به یک پیج اینستاگرام بدون داشتن وب‌سایت اختصاصی.

# ارتباط با سایر مفاهیم
متصل به `KB-KPI-ECOM-001` و `KB-PLAY-LAUNCH-001`.

# تأثیر روی فازهای بعدی
تاکید بر دکمه‌های خرید مستقیم در فاز ۵ و طراحی بسته‌بندی پستی در فاز ۷.

# KPI / Signals
Conversion Rate > 2.5%, Cart Abandonment < 65%.
