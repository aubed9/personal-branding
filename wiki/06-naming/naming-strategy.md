# مفهوم چیست؟
روش‌شناسی مهندسی انتخاب نام برند بر اساس قلمروهای معنایی (توصیفی، استعاره‌ای، اختراعی، تلفیقی، نام بنیان‌گذار).

# چرا اهمیت دارد؟
نام برند باارزش‌ترین دارایی و تنها ظرفی است که در طول سال‌ها با اعتماد و وفاداری پر می‌شود.

# چه زمانی استفاده می‌شود؟
در گام ۱ فاز ۶.

# چه زمانی نباید استفاده شود؟
پیش از تدوین جایگاه‌یابی و گزاره ارزش فاز ۳.

# برای چه نوع کسب‌وکارهایی مهم‌تر است؟
تمام کسب‌وکارهای جدید یا پروژه‌های ری‌برندینگ.

# سؤال‌هایی که برای کشف آن باید پرسیده شود
- نام برند در کدام قلمرو معنایی باید قرار گیرد؟- آیا نام باید توصیفی باشد یا استعاره‌ای و ماندگار؟

# داده‌های موردنیاز
جایگاه فاز ۳، پرسونای فاز ۲، حوزه فعالیت و بازارهای آتی توسعه.

# نحوه تحلیل
تولید خوشه‌های نام در ۵ قلمرو و فیلتر کردن آن‌ها با معیارهای آوایی، املایی و حقوقی.

# مثال ساده
کارواش: قلمرو توصیفی-سرعت: «کارلوکس» یا «برق‌آسا»؛ قلمرو استعاره‌ای: «زلال».

# مثال تخصصی
نرم‌افزار B2B: قلمرو تلفیقی مدرن: «فین‌یار» (ترکیب فینانس + یار)؛ با روانی تلفظ و امتدادپذیری به محصولات دیگر.

# اشتباهات رایج
- انتخاب نام بر اساس سلیقه شخصی دورهمی دوستانه بدون محک استراتژیک.

# KPI / Signals
