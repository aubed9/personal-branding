# هدف

این Knowledge Node قرارداد داخلی فاز ۷ برای تبدیل تصمیم‌های تثبیت‌شدهٔ استراتژی، شخصیت برند و نام به یک سیستم بصری قابل اجراست. این صفحه **منبع حقیقت خارجی** دربارهٔ روان‌شناسی رنگ، استانداردهای دسترس‌پذیری، قوانین چاپ یا benchmarkهای صنعت نیست.

# ورودی‌های لازم

- تصمیم‌های تثبیت‌شدهٔ فاز ۴ دربارهٔ شخصیت و گاردریل‌های هویتی.
- تصمیم‌های تثبیت‌شدهٔ فاز ۶ دربارهٔ نام، شعار و جهت خلاقه.
- محدودیت‌های واقعی کانال‌ها و نقاط تماس کسب‌وکار.
- هر الزام بیرونی فقط زمانی قابل استفاده است که Source/Claim معتبر داشته باشد.

# خروجی‌های داخلی

- معماری پالت رنگ و نقش هر token.
- معماری تایپوگرافی فارسی/لاتین و سلسله‌مراتب کاربرد.
- جهت لوگو، قواعد استفاده و سناریوهای مقیاس.
- قواعد عناصر گرافیکی، عکس، الگو، collateral و نقاط تماس.
- قواعد governance برای جلوگیری از drift بصری.

# منطق فاز

هویت بصری باید از تصمیم‌های قبلی مشتق شود، نه از یک template ثابت. تفاوت در شخصیت، معماری برند، کانال، نوع پیشنهاد و بافتار کسب‌وکار باید بتواند composition بصری متفاوتی ایجاد کند.

# مرز provenance

- هر ادعای علمی دربارهٔ اثر روانی رنگ، ادراک، خوانایی یا رفتار مشتری به External Knowledge Claim معتبر نیاز دارد.
- هر نسبت، threshold یا استاندارد دسترس‌پذیری به منبع رسمی/معتبر و locator نیاز دارد.
- هر الزام حقوقی یا صنفی باید از منبع قانونی تازه و قابل بازتولید بیاید.
- نبود منبع معتبر باید به `REQUIRES_VERIFICATION` یا `NEEDS_RESEARCH` منجر شود، نه حدس.
