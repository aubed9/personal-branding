# کاربرد تصمیمی

این node فقط داده رسمی دوره‌ای شاخص قیمت مصرف‌کننده را برای سنجش فشار تورمی و به‌روزرسانی فرضیات قیمت/هزینه در ایران فراهم می‌کند. از آن نباید به‌تنهایی برای تعیین قیمت، پیش‌بینی آینده یا نسبت‌دادن علت تورم استفاده شود.

# داده تأییدشده

برای مرداد ۱۴۰۵، گزارش مرکز آمار ایران شاخص قیمت مصرف‌کننده خانوارهای کشور را 700.1، تورم ماهانه را 3.4٪، تورم نقطه‌به‌نقطه را 89.0٪ و تورم دوازده‌ماهه را 69.9٪ گزارش می‌کند.

# دامنه و محدودیت

- جمعیت مرجع: خانوارهای کشور.
- دوره مشاهده: مرداد ۱۴۰۵.
- با شاخص بانک مرکزی برای «مناطق شهری» یکسان فرض نشود.
- برای استفاده بعد از پنجره freshness باید دوباره منبع رسمی بررسی شود.
